# Roadmap

Estas são oportunidades de contribuição, sem promessa de prazo.

A beta 0.3.0 adiciona captura nativa e instalador para Windows.

## Próximos passos

- Reproduzir a instalação em outros PCs Windows e Macs e versões suportadas do Chrome/Node.
- Melhorar mensagens para falhas de cópia e mudanças na interface do Figma.
- Oferecer seleção de capturas anteriores no catálogo da extensão.
- Adicionar exemplos públicos e um vídeo curto de uso.
- Internacionalizar o painel; hoje ele está em português.

## Investigações

- Captura nativa no Linux.
- Melhor cobertura de componentes de bibliotecas sem depender de APIs privadas.
- Publicação na Chrome Web Store e caminho de atualização mais simples.
- Formatos adicionais de integração com agentes, preservando orçamento de contexto.

Abra uma issue descrevendo o problema que quer resolver antes de começar uma mudança grande. A prioridade é manter a leitura local, os escopos explícitos e a evidência de conteúdo disponível.
