Instalar Figma Local

1. Prepare o leitor e a skill

No pacote Figma Local, abra Instalar.cmd no Windows ou Instalar.command no Mac. O instalador prepara o leitor no seu usuário e instala a skill para o Codex.

Esta versão usa Windows ou macOS e uma versão LTS mantida do Node.js, 22 ou posterior.

2. Carregue a extensão

Abra chrome://extensions, ative o modo do desenvolvedor e escolha Carregar sem compactação. Selecione a pasta extension indicada na página que o instalador abre.

3. Capture o que precisa

Abra o Figma no Chrome e entre com sua conta. No painel Figma Local, escolha Capturar seleção ou Capturar página e confirme no botão que aparece dentro do Figma.

Se a captura automática não funcionar, use Copiar no Figma e depois Importar cópia manual no painel.

4. Use no Codex

Selecione as telas no catálogo e clique Copiar pedido para o Codex. Em uma nova conversa do Codex, use $figma-local para consultar a captura.

O índice fica no seu computador. Capture novamente quando o design mudar.
