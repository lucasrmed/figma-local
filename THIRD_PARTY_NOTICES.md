# Dependências de terceiros

O leitor usa [figma-clipboard-mcp](https://github.com/georg3103/figma-clipboard-mcp), versão 0.2.0, para decodificação local. Não utiliza o servidor MCP desse pacote. As dependências e suas versões estão no lockfile; suas licenças acompanham a instalação via npm.
